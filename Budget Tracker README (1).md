# 📊 Executive Budget & Expense Tracker

An executive-grade, interactive, single-page budget planner and expense ledger designed for shared bachelor living. Featuring a bright glassmorphism UI, this dashboard allows you to dynamically adjust your monthly income, manage master expense categories, and log date-wise sub-expenses inside expandable category windows.

## ✨ Key Features

*   **💰 Live Adjustable Salary:** Modify your total monthly income on the fly using direct number inputs or quick `-5k` / `+5k` step buttons.
*   **📅 Date-Wise Sub-Category Windows:** Every expense category features an expandable **"Details & Logs"** window where you can record individual date-wise transactions (e.g., *Petrol Fill-up, Mess Advance, Wi-Fi Split*) and sync the category total with one click.
*   **📈 Real-Time Interactive Visuals:** Powered by Chart.js, the live doughnut chart and utilization progress bar automatically recalculate shares, percentages, and unallocated funds as you type or slide.
*   **🎛️ Zero-Limit Precision Controls:** Adjust budgets down to `0 PKR` with smooth range sliders or direct numeric inputs, and create or delete custom categories anytime.
*   **💾 Automatic Local Storage:** All categories, salary adjustments, and date-wise logs are automatically saved in your browser's `localStorage` so your data remains intact when you refresh or close the tab.
*   **📄 Executive ASCII Text Report:** Generate and copy a clean, formatted `.TXT` ledger of your entire monthly breakdown and sub-entries for sharing on WhatsApp, email, or notes.

## 🛠️ Technologies Used

*   **HTML5** – Single-file application structure
*   **Tailwind CSS (CDN)** – Responsive glassmorphism styling and layout
*   **Vanilla JavaScript (ES6+)** – State management, `localStorage` persistence, and DOM rendering
*   **Chart.js (CDN)** – Dynamic doughnut chart visualization
*   **Google Fonts** – *Poppins* (UI typography) & *JetBrains Mono* (ASCII ledger report)

## 🚀 How to Use

### 1. Live Web App (GitHub Pages)
Open the live GitHub Pages URL associated with this repository on any mobile phone or desktop browser to start tracking your budget immediately.

### 2. Local Setup
1. Download or clone this repository.
2. Ensure the main file is named `index.html`.
3. Open `index.html` in any web browser—no servers or installations required.
